# Neovim 原生默认快捷键 (v0.12.5)

> 本文只列 **Neovim 自带、不依赖任何插件**的键位。
> §1 是 Neovim 相对 Vim 新增/改写的默认映射（有明确出处：`runtime/lua/vim/_core/defaults.lua`）；
> §2 起是经典 Vim 键位速查。
> **本配置覆盖了哪些原生键，见 §8。**
> 自己查：`:map` / `:nmap` / `:vmap` / `:imap`；`:verbose map <C-x>` 能看到是谁定义的。

---

## 1. Neovim 新增/改写的默认映射

### 1.1 编辑类

| 键 | 模式 | 作用 |
|---|---|---|
| `Y` | n | `y$`（Vim 里是整行 yank） |
| `&` | n | `:&&` 用同样的替换标志重复 `:s` |
| `<C-L>` | n | `nohlsearch` + `diffupdate` + 重绘 |
| `<C-U>` | i | 删除到行首，且不破坏撤销点（`<C-G>u<C-U>`） |
| `<C-W>` | i | 删除前一个词，且不破坏撤销点 |
| `*` `#` | x | 搜索选中内容（不用先 yank） |
| `Q` | x | 行块可视模式下，对选中每一行重复执行上次录制的寄存器（不进入 Ex 模式） |
| `@` | x | 同 `Q` |
| `gx` | n / x | 用系统程序打开光标下的路径或 URL；LSP 支持时走 `documentLink` |
| `gc{motion}` / `gcc` | n / x | 注释/取消注释（内建 `vim._comment`，**不需要 Comment.nvim**） |
| `gc` | o | 注释文本对象，如 `gcip` |

### 1.2 LSP 全局默认（启动时就映射，没挂 LSP 会报"不支持"而不是静默）

| 键 | 模式 | 作用 |
|---|---|---|
| `grn` | n | 重命名 `vim.lsp.buf.rename()` |
| `gra` | n / x | 代码操作 `vim.lsp.buf.code_action()` |
| `grr` | n | 引用 `vim.lsp.buf.references()` |
| `gri` | n | 实现 `vim.lsp.buf.implementation()` |
| `grt` | n | 类型定义 `vim.lsp.buf.type_definition()` |
| `grx` | n | 执行 codelens `vim.lsp.codelens.run()` |
| `gO` | n | 文档符号 `vim.lsp.buf.document_symbol()` |
| `<C-S>` | i / s | 函数签名帮助 `vim.lsp.buf.signature_help()` |
| `K` | n | 悬停文档（仅当 `keywordprg` 为空且 `K` 未被映射时；否则是 Vim 的 `keywordprg`） |

### 1.3 诊断 / 列表导航（vim-unimpaired 风格）

| 键 | 作用 | 键 | 作用 |
|---|---|---|---|
| `]d` / `[d` | 下/上一条诊断 | `]D` / `[D` | 最后/第一条诊断 |
| `<C-W>d` | 浮窗显示光标处诊断 | `<C-W><C-D>` | 同上 |
| `]q` / `[q` | quickfix 下/上一条 | `]Q` / `[Q` | quickfix 最后/第一条 |
| `]<C-Q>` / `[<C-Q>` | quickfix 下/上一个文件 | | |
| `]l` / `[l` | location list 下/上一条 | `]L` / `[L` | location list 最后/第一条 |
| `]<C-L>` / `[<C-L>` | location list 下/上一个文件 | | |
| `]a` / `[a` | 下一个/上一个参数文件 | `]A` / `[A` | 最后/第一个参数文件 |
| `]t` / `[t` | 下一个/上一个标签页 | `]T` / `[T` | 最后/第一个标签页 |
| `]<C-T>` / `[<C-T>` | **预览窗口**里的 tag 导航（`:ptnext` / `:ptprevious`，配合 `:ptag`） | | |
| `]b` / `[b` | 下一个/上一个 buffer | `]B` / `[B` | 最后/第一个 buffer |
| `]<Space>` / `[<Space>` | 在下方/上方插入空行（保持光标） | | |

### 1.4 语法树（treesitter）选择

| 键 | 模式 | 作用 |
|---|---|---|
| `]n` / `[n` | x | 扩大/缩小选择到下一个/上一个同级节点 |
| `]N` / `[N` | x | 选择下一个/上一个兄弟节点 |
| `an` / `in` | x / o | 选中父节点 / 子节点（LSP 激活且无 treesitter 时回退到 `selection_range`） |

> `i_<Tab>` / `i_<S-Tab>`：代码片段激活时跳转到下一个/上一个占位符，否则是普通 Tab。
> `[[` / `]]`：**只在终端 buffer（`:terminal`）里**被映射为在 shell 提示符之间跳转；普通 buffer 里仍是 Vim 的"节首/节尾"。

## 3. 编辑

| 键 | 作用 | 键 | 作用 |
|---|---|---|---|
| `i` `a` | 光标前 / 后插入 | `I` `A` | 行首 / 行尾插入 |
| `o` `O` | 下方 / 上方新开一行 | `R` | 替换模式 |
| `r{c}` | 替换一个字符 | `~` | 切换大小写 |
| `x` `X` | 删除光标处 / 前一个字符 | `s` `S` | 替换字符 / 整行 |
| `d{motion}` `dd` `D` | 删除 / 整行 / 到行尾 | `c{motion}` `cc` `C` | 删除并进入插入 |
| `y{motion}` `yy` `Y` | 复制（`Y` 在 nvim 里是 `y$`） | `p` `P` | 粘贴到后 / 前 |
| `gp` `gP` | 粘贴并把光标移到内容之后 | `]p` | 粘贴并按当前行缩进 |
| `J` `gJ` | 合并下一行（带 / 不带空格） | `.` | 重复上次修改 |
| `u` `<C-r>` | 撤销 / 重做 | `U` | 撤销整行的修改 |
| `>>` `<<` | 缩进 / 反缩进 | `==` `={motion}` | 自动缩进 |
| `gcc` `gc{motion}` `gcip` | 注释（nvim 内建） | `<C-a>` `<C-x>` | 数字 +1 / -1（可视模式同样有效） |
| `gu{motion}` `gU{motion}` `g~{motion}` | 转小写 / 大写 / 翻转 | `guu` `gUU` `g~~` | 整行版本 |

**插入模式常用**：`<C-w>` 删词、`<C-u>` 删到行首、`<C-r>{reg}` 插入寄存器、`<C-r>=` 表达式寄存器、
`<C-o>{cmd}` 执行一条普通模式命令、`<C-t>`/`<C-d>` 缩进、`<C-n>`/`<C-p>` 关键字补全、
`<C-x>` 是补全子菜单（`<C-x><C-f>` 文件名、`<C-x><C-l>` 整行、`<C-x><C-o>` omnifunc）。

## 4. 操作符 + 文本对象

## 5. 搜索与替换

| 键 | 作用 |
|---|---|
| `/` `?` | 向下 / 向上搜索（再按 `/` 回车重复上次搜索） |
| `n` `N` | 下一个 / 上一个匹配 |
| `*` `#` | 向下 / 向上搜索光标下的单词 |
| `g*` `g#` | 同上，但不要求整词匹配 |
| `:s/old/new/` | 当前行替换；加 `g` 全行、加 `c` 逐个确认 |
| `:%s/old/new/g` | 全文件替换；`:'<,'>s/...` 只替换可视选区 |
| `&` | 用上次的标志重复 `:s` |
| `:g/pat/cmd` `:v/pat/cmd` | 对匹配 / 不匹配的行执行命令 |
| `:noh` | 取消高亮（本配置另有 `<leader>nh` 和 `<C-g>`） |

**命令行（`:` 或 `/` 后）**：`<C-r><C-w>` 插入光标下的词、`<C-r><C-f>` 插入文件名、`<C-p>`/`<C-n>` 翻历史、
`<C-f>` 打开命令行窗口（`q:` 命令历史、`q/` 搜索历史）、`:!cmd` 执行外部命令、`:r !cmd` 读入命令输出、`:.!cmd` 用命令过滤当前行。

## 8. 本配置覆盖或改写的原生键

| 原生键 | 原生作用 | 本配置改成 | 影响 |
|---|---|---|---|
| `n <C-x>` | 数字 -1 | Emacs 前缀（`C-x C-s` 等） | 前缀超时（`timeoutlen=500ms`）后 `C-x` 仍可做减一；**插入模式 `<C-x>` 补全完全不受影响** |
| `n <C-g>` | 显示文件名/光标位置 | 取消搜索高亮 | 文件信息可用 `:f` 查看 |
| `n/v/o <C-j>` `<C-k>` | `<C-j>` 下移一行；`<C-k>` 无定义 | 上下移动 5 行 | visual 模式下改为移动选中代码块 |
| `v >` `v <` | 缩进后退出可视 | 缩进并保持选中（`>gv`） | 更顺手，无副作用 |
| `n -` | 上移到上一行首个非空字符 | 打开当前文件所在目录（yazi.nvim） | 想用原生行为可以用 `k^` |
| `i <CR>` | 换行 | 由 nvim-autopairs 接管 | 只有在括号/引号内换行时才多自动缩进闭合，普通换行不变 |
| `n gd` | 跳到局部声明 | LSP 定义（**仅 LSP 挂载时 buffer-local**） | 无 LSP 时 `gd` 仍是原生行为；`gD` 未改动 |
| `n gx`（仅 markdown） | 用系统程序打开路径/URL | `:Markview open`（打开 markdown 链接） | **只在 markdown buffer 里**，其它文件类型 `gx` 仍是原生 |
| `i <Tab>` `<S-Tab>` | 代码片段占位符跳转 | 由 blink.cmp 接管（`super-tab`），片段跳转是其内部回退 | 见 `keymaps-plugins.md` §4 |
| `n <F5>` | 未定义 | 打开/关闭终端（snacks） | 无冲突 |

**未被覆盖、可放心使用的原生键**：`grn` `gra` `grr` `gri` `grt` `grx` `gO` `K` `gc` `gcc` `gx`（非 markdown）`]d` `[d` `]D` `[D`
`<C-W>d` `]q` `[q` `]Q` `[Q` `]l` `[l` `]a` `[a` `]t` `[t` `]b` `[b` `]<Space>` `[<Space>` `]n` `[n` `an` `in` `*` `#` `Y` `&` `<C-L>`，
以及全部 `<C-w>` 窗口操作、`<C-o>`/`<C-i>`、`g;`/`g,`、`%`、`f/t/;/,` 等。

> 另外注意：diffview / trouble / yazi / markview 会在**自己的 buffer 里**设置 buffer-local 键位
> （例如 diffview 窗口里 `<leader>e` 是"聚焦文件面板"、trouble 窗口里 `q` 是关闭），
> 这些不会影响普通文件窗口，详见 `keymaps-plugins.md`。
